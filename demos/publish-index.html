FoCS experiments

Experiments for teaching Foundations of Computer Science, the first-year functional programming course in OCaml at Cambridge. Everything runs in your browser: OCaml is compiled to JavaScript, and the checks run on your machine, with no server. These are prototypes, not course material.

  • Exercises that check more than answers: whether a function is tail recursive, how its work grows as the input doubles, whether it uses a library function it shouldn't, and finding an input that tells two functions apart. (With the answers filled in.)
  • Examples first: write examples of what a function should do; they are checked against hidden correct versions, and against wrong ones made from common mistakes, after Examplar.
  • Predict the next step: box-and-pointer diagrams of rev with an accumulator and of tree traversals, where you choose the next state before it is shown.
  • Stepping OCaml: Kenichi Asai's stepper (Ochanomizu University), compiled to run in the page, with the course notes' examples and a mode where you type the next step first.

Built on x-ocaml. Jon Ludlam, November 2026.
